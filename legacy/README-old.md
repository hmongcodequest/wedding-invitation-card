# 💍 ບັດເຊີນງານແຕ່ງງານ (Wedding Invitation Card)

ເວັບແອັບພລິເຄຊັນໜ້າດຽວ (Single-page Application) ສຳລັບສ້າງ ແລະ ພິມບັດເຊີນງານແຕ່ງງານເປັນພາສາລາວ ແບບຄລາສສິກ ດ້ວຍສີທອງ-ຄຣີມ ທີ່ສາມາດປັບຊື່ແຂກໄດ້ທຸກຄົນ ແລະ ພິມອອກເປັນບັດຂະໜາດຈິງໄດ້ທັນທີ.

## 1. ຄຸນສົມບັດຫຼັກ

- **ບັດ 2 ໜ້າ**: ໜ້າປົກ (ຊື່ແຂກ + ຊື່ຄູ່ບ່າວສາວ + ວັນທີ/ສະຖານທີ່) ແລະ ໜ້າເນື້ອໃນ (ກຳນົດເວລາ + ຂໍ້ມູນຕິດຕໍ່ + ລາຍເຊັນ)
- **ຄົ້ນຫາ ແລະ ເລືອກແຂກ**: ພິມຊື່ແຂກເພື່ອຄົ້ນຫາ, ບັດຈະປ່ຽນຊື່ແຂກໃຫ້ອັດຕະໂນມັດ
- **2 ຂະໜາດເຈ້ຍ**:
  - 📄 A4 (210×297 ມມ) — ບັດໃຫຍ່
  - 💌 A7 (12.7×17.8 ຊມ / 5×7 ນິ້ວ) — ບັດເຊີນຄລາສສິກ
- **ພິມໄດ້ 3 ແບບ**: ພິມໜ້າປົກ, ພິມໜ້າເນື້ອໃນ, ຫຼື ພິມທັງສອງໜ້າ
- **ຕິດຕາມສະຖານະການພິມ**: ໝາຍແຂກທີ່ພິມແລ້ວ (✅) ຈະຖືກເຊື່ອງອອກຈາກການຄົ້ນຫາ (ເກັບໃນ localStorage)
- **ຕາຕະລາງລາຍຊື່ແຂກ**: ຄົ້ນຫາ, ກັ່ນຕອງຕາມຕຳແໜ່ງ/ສະຖານະ/ສະຖານະການພິມ, ແບ່ງໜ້າ (5/10/20 ຄົນຕໍ່ໜ້າ)
- **ຮູບຫົວໃຈ**: ຮູບຄູ່ບ່າວສາວໃນກອບຮູບຫົວໃຈ
- **ພາສາລາວ 100%**: ຟອນ Noto Sans Lao Looped + Playfair Display ສຳລັບຕົກແຕ່ງ

## 2. ໂຄງສ້າງໄຟລ໌

| ໄຟລ໌ | ລາຍລະອຽດ |
|---|---|
| `index.html` | ແອັບພລິເຄຊັນຫຼັກ (HTML + CSS + JavaScript ໃນໄຟລ໌ດຽວ) |
| `data.json` | ຂໍ້ມູນງານແຕ່ງງານ: ຄູ່ບ່າວສາວ, ວັນທີ, ສະຖານທີ່, ລາຍຊື່ແຂກ |
| `wedding-invitation-card.xlsx` | ໄຟລ໌ Excel ລາຍຊື່ແຂກ (ແຫຼ່ງຂໍ້ມູນຫຼັກ) |
| `xlsx.full.min.js` | ຫ້ອງສະໝຸດ SheetJS ສຳລັບອ່ານໄຟລ໌ Excel |
| `placeholder-photo.svg` | ຮູບຄູ່ບ່າວສາວຊົ່ວຄາວ (ປ່ຽນໄດ້) |
| `layout-test.html` | ເຄື່ອງມືກວດສອບຂະໜາດບັດ A7 ແລະ ເລຍເອົດ 3 ຖັນ |
| `viewport-test.html` | ເຄື່ອງມືກວດສອບການສະແດງຜົນໃນຂະໜາດໜ້າຈໍຕ່າງໆ |

## 3. ວິທີເປີດໃຊ້ງານ

ບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງ ຫຼື ບໍ່ມີ build step — ພຽງແຕ່ເປີດຜ່ານເຊີບເວີສະເຕຕິກ:

```bash
# ວິທີທີ່ 1: Python
python -m http.server 8000

# ວິທີທີ່ 2: Node.js (npx)
npx serve

# ວິທີທີ່ 3: PHP
php -S localhost:8000
```

ແລ້ວເປີດບຣາວເຊີໄປທີ່ **http://localhost:8000**

> ⚠️ ບໍ່ຄວນເປີດ `index.html` ໂດຍກົງ (double-click) ເພາະ `fetch()` ຈະບໍ່ເຮັດວຽກກັບ `file://` protocol.

## 4. ຂໍ້ມູນງານແຕ່ງງານ (data.json)

ໂຄງສ້າງຂໍ້ມູນ:

```json
{
  "bride": { "title": "ນາງ", "first_name": "ວີ", "last_name": "ເຮີ" },
  "groom": { "title": "ທ້າວ", "first_name": "ກົ່ງ", "last_name": "ກື້" },
  "location": "ບ້ານ ພູວຽງນ້ອຍ, ເມືອງ ພູຄູນ, ແຂວງ ຫຼວງພະບາງ",
  "date": "ວັນທີ່ 14 ເດືອນ 9 ປີ 2026",
  "time": "ເວລາ 11:30 ນາທີ ຕອນທ່ຽງ",
  "guests": [
    { "title": "ທ່ານ", "first_name": "ຄຳສຸດ", "last_name": "ພັນທະນາ", "position": "ດຣ.", "ready": "ຄອບຄົວ" }
  ]
}
```

- `position` — ຕຳແໜ່ງ/ກຸ່ມແຂກ (ໃຊ້ກັ່ນຕອງ)
- `ready` — ສະຖານະການຕອບຮັບ (ຄອບຄົວ, ພັນລະຍາ, ສາມີ...)

## 5. ການໂຫຼດຂໍ້ມູນຈາກ Excel

ແອັບຈະພະຍາຍາມອ່ານ `wedding-invitation-card.xlsx` ກ່ອນ; ຖ້າບໍ່ພົບ ຈຶ່ງຕົກລົງໄປໃຊ້ `data.json`.

**ໂຄງສ້າງຕາຕະລາງ Excel (ແຊັດທຳອິດ):**

| ຖັນ | ຂໍ້ມູນ |
|---|---|
| A | ຄຳນຳໜ້າແຂກ (title) |
| B | ຊື່ແຂກ (first_name) |
| C | ນາມສະກຸນແຂກ (last_name) |
| D | ຕຳແໜ່ງ (position) |
| E | ສະຖານະ (ready) |
| F–H | ສາວ: ຄຳນຳໜ້າ, ຊື່, ນາມສະກຸນ (ແຖວທີ 3) |
| I–K | ບ່າວ: ຄຳນຳໜ້າ, ຊື່, ນາມສະກຸນ (ແຖວທີ 3) |
| L | ສະຖານທີ່ (ແຖວທີ 2) |
| M | ວັນທີ (ແຖວທີ 2) ແລະ ເວລາ (ແຖວທີ 3) |

> 💡 ຫຼັງຈາກແກ້ໄຟລ໌ Excel ແລ້ວ ພຽງແຕ່ refresh ໜ້າເວັບ — ແອັບຈະອ່ານໄຟລ໌ໃໝ່ອັດຕະໂນມັດ (ມີ cache-busting ແລ້ວ).

## 6. ຂະໜາດເຈ້ຍ ແລະ ການພິມ

### ການເລືອກຂະໜາດ
ເລືອກຂະໜາດເຈ້ຍຈາກກ່ອງເລືອກຢູ່ແຖບເທິງ — ບັດ ແລະ ການຈັດວາງຈະປ່ຽນອັດຕະໂນມັດ (ຈື່ການເລືອກໄວ້ໃນ localStorage).

### ການຕັ້ງຄ່າພິມ

| ຂະໜາດ | ຕັ້ງຄ່າເຈ້ຍໃນກ່ອງພິມ | ຂອບ (Margin) |
|---|---|---|
| A4 | A4 (210×297 ມມ) | 12 ມມ |
| A7 | 12.7×17.8 ຊມ (5×7 ນິ້ວ) | **0 ມມ** |

- ກົດ **🖨️ ພິມໜ້າປົກ** ຫຼື **🖨️ ພິມໜ້າເນື້ອໃນ** ເພື່ອພິມແຕ່ລະໜ້າ
- ກົດ **🖨️ ພິມທັງສອງໜ້າ** ເພື່ອພິມຄົບທັງສອງໜ້າ
- ເປີດ "Background graphics" ໃນກ່ອງພິມ ເພື່ອໃຫ້ສີພື້ນຫຼັງ ແລະ ສີທອງອອກຄົບ

## 7. ການຈັດການລາຍຊື່ແຂກ

- **ຄົ້ນຫາແຂກ**: ພິມຊື່ໃນກ່ອງຄົ້ນຫາ — ແຂກທີ່ພິມແລ້ວຈະຖືກເຊື່ອງອັດຕະໂນມັດ
- **ໝາຍສະຖານະການພິມ**: ກົດປຸ່ມ ✅/⬜ ໃນຕາຕະລາງ ເພື່ອໝາຍແຂກທີ່ພິມແລ້ວ (ເກັບໃນ localStorage ຂອງບຣາວເຊີ)
- **ກັ່ນຕອງ**: ຕາມຕຳແໜ່ງ, ສະຖານະ, ສະຖານະການພິມ
- **URL parameters**: ການກັ່ນຕອງຈະຖືກບັນທຶກໃສ່ URL (`?search=...&position=...&ready=...&printed=...`) ເພື່ອແຊຣ໌ລິ້ງໄດ້

## 8. ການປັບແຕ່ງສີ ແລະ ຮູບແບບ

ສີທັງໝົດຖືກກຳນົດເປັນ CSS variables ຢູ່ຕົ້ນ `index.html`:

```css
:root {
    --gold: #c9a227;        /* ສີທອງ */
    --gold-light: #e8d48b;
    --gold-dark: #a8841f;
    --cream: #fdf8ef;       /* ສີຄຣີມ */
    --ink: #3d3a34;         /* ສີຕົວໜັງສື */
    --rose: #b76e79;        /* ສີບົວກຸຫຼາບ */
    --white: #ffffff;
}
```

- **ປ່ຽນຮູບຄູ່ບ່າວສາວ**: ແທນທີ່ `placeholder-photo.svg` ດ້ວຍຮູບຈິງ (ຮູບຈະຖືກຕັດເປັນຮູບຫົວໃຈອັດຕະໂນມັດ)
- **ປ່ຽນຟອນ**: ແກ້ `@import` ຂອງ Google Fonts ຢູ່ເທິງສຸດຂອງ `index.html`
- **ປ່ຽນຂໍ້ຄວາມ**: ແກ້ຂໍ້ຄວາມພາສາລາວໂດຍກົງໃນ HTML (ພາກສ່ວນ `.invite-text`, `.date-label`, ຕາຕະລາງເວລາ...)
